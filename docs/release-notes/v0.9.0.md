symfn 0.9.0 is the first release: a Rust and Python library for
computing with symmetric functions, the six classical bases, the
Hall–Littlewood, Macdonald, LLT and Jack families above them, and
Schubert polynomials. Each basis is a distinct type over a coefficient
ring the caller chooses. Every value that leaves the library is exact
or the call fails loudly.

## Install

```sh
cargo add symfn        # Rust 1.87 or later
pip install symfn      # CPython 3.9 or later
```

Wheels are attached below for fourteen platforms; anything else needs
to build from the source distribution, which needs only a Rust
toolchain. The Rust reference is at docs.rs/symfn and the Python
reference at symfn.readthedocs.io, and the `symfn-docs` tarball below
holds both, offline.

## Comparison to Sage

Sage offers one, if not the, most complete implementations for
symmetric functions, using Symmetrica for efficient computations with
for the classical symmetric functions. This library is designed to be
a drop-in replacement for symmetrica which offers significant performance
improvements (although can still be used independently from both Python
and Rust).

The `symfn` branch of Sage can be found at
https://github.com/mwhansen/sage/tree/symfn and passes all of Sage's
symmetric function tests.

| Computation                                           | Ratio       |
|-------------------------------------------------------|-------------|
| Kostka–Foulkes `K_{λμ}(t)`, per pair                  | 30–40×      |
| Kostka–Foulkes, a whole column                        | 880×        |
| Macdonald `P`, `Q`, `J`, every shape through degree 9 | 94×         |
| The `(q,t)`-Kostka matrix, degree 12                  | 18×         |
| `∇e_n`, degrees 8 to 13                               | 16–27×      |
| Jack `m → P`, `m → Q`, `m → J`, degree 10             | 960–1090×   |
| LLT, whole-degree tables to `k = 4`                   | 700–19,100× |
| A Kronecker coefficient, degrees 12 to 24             | 40–2350×    |
| Reduced Kronecker product `st[4,3]²`                  | 3400×       |
| Plethysm                                              | 25–40×      |
| Classical-basis conversions, degrees 8 to 20          | 2–8×        |
| Hall–Littlewood `Q'`, end to end                      | 2.5–3.4×    |

Note that there is some overhead in converting the Rust objects to Python
so the actual performance increases within Sage will be a bit more modest.

There is also some additional functionality not present in Sage such as
Macdonald operators Δ, Δ′ and Θ.
